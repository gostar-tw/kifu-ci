    給工程師

    這支工具最後會貼在 Blogger 網頁上（gostar.tw/p/kifu.html），但你不用碰那個平台。把這份改好、能雙擊打開就跑，回傳給業主即可；上架前的平台處理有人接手。

    三條硬規則

    1. 維持單一 HTML 檔。不拆 css/js、不用打包工具、不用 npm、不用模組匯入。外部資源只允許現有的 Google Fonts @import。
    2. 不要改成 iframe 架構。分享功能靠 location.hash，進 iframe 就失效。
    3. 不要改 enc() 與 dec3() 的既有欄位。這兩支是分享碼的編解碼，改了既有欄位的順序或意義，已發出去的連結會全斷。要加資料只能往分享碼尾端加欄位，舊碼少的欄位要讀成空值。改之前先討論。

    實務事項

    • 存檔編碼固定 UTF-8（無 BOM）。存成 Big5 / ANSI 中文會全部變亂碼。原檔已把所有非中文符號寫成 \u25b3 這種跳脫，請不要還原成符號。
    • 所有 CSS 必須寫在 #gk 作用域內（或 .gk- 開頭的浮動層）。正式環境有佈景自己的樣式，一條裸的 * 或 body 就會把整個網站弄掉。
    • 新增的全域 id 一律 gk 開頭。
    • 改完把 APP_VERSION 往上加，頁尾會顯示。
    • 頁面最上方的【自我檢查】會自動跑，回傳前請確認全數通過（把視窗縮到 390px 寬再看一次）。
    • 回傳時附一段話說明改了哪些地方就好。

    可以隨意改的

    版面、配色、按鈕配置、圖示、互動、新增功能——除上述限制外都不設限。畫面上方黑條與【自我檢查】是本機預覽外殼，正式環境不存在，請勿修改。
